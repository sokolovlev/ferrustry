## Минимальный вертикальный срез (этап 1)

Headless, без графики. Карта 64×64 из seed; на ней:
руда железа → **бур** → **конвейеры** (с поворотами) → **печь** (руда + энергия → слиток) →
**ядро** (хранилище). Один генератор и узел энергии. Результат проверяется тестом:
«за N тиков в ядре ровно K слитков», и тот же сценарий сохраняется, загружается и
продолжается с тем же хешем состояния.
