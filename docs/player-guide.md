# Руководство игрока

Ferrustry — игра про автоматизацию производства и защиту базы. Вы добываете руду, перерабатываете её
на заводах, связанных лентами, и строите оборону: волны врагов идут к вашему ядру.

Точные числа всех построек и врагов — в [справочнике контента](content-reference.md) (он генерируется
из данных игры и всегда актуален). Здесь — как всё работает и как этим пользоваться.

## Запуск

```bash
cargo run --release -p ferrustry-client
```

Нужны процессор с AVX2 (x86_64) или Apple Silicon и видеокарта с Vulkan, DirectX 12 или Metal.
На Linux — пакеты `libvulkan1` и `libxkbcommon-x11-0`.

## Кампания

**CAMPAIGN** в главном меню — цепочка секторов. Каждый сектор — карта со своими целями; победа
открывает следующий сектор и новые постройки. В начале доступны только ленты, разветвитель, бур,
плавильня, ветряк, энергоузел, пушка и стена.

| Сектор | Цели | Открывает |
|---|---|---|
| 1. ASHFALL LANDING (малая карта, лёгкая) | сделать 150 железных слитков, пережить 3 волны | кузница стали, радиатор, тепловая труба, сортировщик, переполнитель, мост |
| 2. BROKEN FOUNDRY (средняя, обычная) | отремонтировать 3 руины, сделать 40 стали, пережить 6 волн | дуговая турель, батарея, топливный генератор, склад, трубы, конденсатор, градирня |
| 3. THE LONG NIGHT (большая, сложная) | пережить 12 волн | тепловая машина |

Цели и прогресс — в левом нижнем углу. «Сделать» считает только добытое бурами и выплавленное —
возврат стоимости при сносе не в счёт. Волна пережита, когда её враги перебиты или пришла следующая.
Когда все цели выполнены, игра встаёт на паузу: **CAMPAIGN** — к выбору сектора, **KEEP PLAYING** —
играть дальше. Пройденный сектор можно переиграть. Прогресс хранится в `ferrustry-campaign.txt`.

## Новая партия

**NEW GAME** открывает настройки:

| Параметр | Варианты | Что меняет |
|---|---|---|
| Размер карты | малая 128×96, средняя 192×128, большая 320×200 | Площадь и число точек появления врагов (2 / 3 / 4) |
| Сложность | лёгкая, обычная, сложная | Темп волн: первая волна через 8 / 5 / 3 мин, затем каждые 3 / 2 / 1,5 мин |
| Seed | число или RANDOM | Одинаковый seed — одинаковая карта на любом компьютере |

Карта генерируется так, что старт всегда честный: ядро в центре, вокруг — ровная площадка, железная
руда в 11–20 тайлах, уголь в 14–24 тайлах, у каждой точки появления врагов есть путь к ядру.
Вначале у вас только ядро и **300 железных слитков**.

## Редактор карт

**MAPS** в главном меню открывает список карт из папки `maps/` рядом с игрой: у каждой карты — размер,
число точек появления врагов и кнопки **PLAY** (начать партию) и **EDIT** (открыть в редакторе).
**NEW MAP** открывает редактор на карте, созданной генератором по настройкам новой игры (размер,
сложность, seed). Слева — инструменты, внизу — действия.

| Инструмент | Что делает |
|---|---|
| BASALT, ASH, SLAG POOL | Заливает пол кистью. На шлаке нельзя строить и по нему не ходят враги; руда с него убирается |
| IRON VEIN, CARBON SEAM | Кладёт руду (только на пол, где можно строить) |
| CLEAR ORE | Убирает руду |
| ENEMY SPAWN | Клик ставит точку появления врагов (красный квадрат), клик рядом с ней — убирает. До 16 точек |
| CORE | Ставит ядро |
| REMOVE BUILDING | Сносит постройки под кистью |
| BRUSH | Размер кисти: 1, 3, 5 или 9 тайлов |
| WAVES | Темп волн: выключены, лёгкий, обычный, сложный |
| START | Стартовый запас железных слитков |

ЛКМ рисует (можно протягивать), ПКМ стирает руду и постройки. Под постройками пол и руда не
меняются. Камера — как в игре (СКМ, WASD, колесо). **Z** / **UNDO** отменяет последний мазок или клик,
**Y** / **REDO** повторяет (до 64 шагов; темп волн и стартовый запас в историю не входят).

**GENERATE** — новая случайная карта, **BLANK** — пустая карта того же размера, **SAVE** — сохранить
(новую карту — в следующий свободный файл `maps/map-001.fmap`, `map-002.fmap`…, открытую — в её файл),
**MAPS** — к списку карт, **PLAY** — начать партию на этой карте, **BACK** или **Esc** — в главное меню.
Звёздочка у имени карты значит, что есть несохранённые изменения: тогда GENERATE, BLANK, MAPS и BACK
срабатывают со второго нажатия. Файлы карт можно переименовывать и копировать — список покажет их
под новыми именами. Перед стартом редактор проверяет, что есть ядро, а при
включённых волнах — что есть точки появления и от каждой можно дойти до ядра.

Файл карты хранит пол, руду и постройки по именам, поэтому переживает обновления игры; если чего-то
из карты в игре больше нет, загрузка сообщит, чего именно.

## Управление

| Клавиша / мышь | Действие |
|---|---|
| **1–6** или клик по слоту | Выбрать постройку во вкладке |
| **Tab** или клик по вкладке | Сменить вкладку (LOGISTICS, PRODUCTION, DEFENSE, POWER, FLUIDS+HEAT) |
| ЛКМ | Построить |
| Протяжка ЛКМ | Линия построек; ленты поворачивают уголком |
| **R** | Повернуть |
| ПКМ | Снять инструмент |
| Протяжка ПКМ | Снести всё в рамке (стоимость возвращается) |
| Клик по постройке без инструмента | Инспектор: буферы, прогресс, энергия, тепло; у сортировщика — выбор фильтра |
| **C** + рамка | Скопировать постройки в схему; затем клик — вставить, **R** — повернуть, ПКМ/Esc — отмена |
| **F6 / F7** | Сохранить / загрузить схему (`ferrustry-schematic.fschem`) |
| **WASD**, стрелки, СКМ | Камера |
| Колесо | Масштаб |
| **Пробел** | Пауза |
| **+ / −** | Скорость симуляции |
| **F5 / F9** | Быстрое сохранение / загрузка (`ferrustry-quicksave.fsave`) |
| **F1** | Справка |
| **Esc** | Меню |

## Экономика

Стройка оплачивается из ядра. Снос возвращает полную стоимость; постройка, **разрушенная врагами**,
не возвращает ничего — её содержимое тоже теряется. Ядро хранит до 4000 каждого предмета.

## Первая производственная цепочка

```
бур на железной руде → лента → плавильня (+ энергия) → лента → ядро
```

1. **Бур** (2×2) ставится на руду. Скорость пропорциональна числу тайлов руды под ним: на 4 тайлах —
   0,75 руды/с, на 2 — вдвое медленнее. Бур выгружает добычу в соседние ленты и заводы.
2. **Лента** везёт до 7,5 предметов/с. Протяните её от бура к плавильне.
3. **Плавильня** превращает 2 руды в 1 слиток за 1 с и потребляет 4 энергии/тик. Ей нужно ~2,7 бура
   на полной руде, чтобы работать без простоя.
4. **Ветряк** даёт 2 энергии/тик — двух ветряков хватает одной плавильне. Энергопостройки,
   касающиеся друг друга сторонами, образуют сеть; **энергоузел** связывает всё в радиусе 6 тайлов.
5. Лента от плавильни к ядру — и слитки начинают копиться.

Если завод стоит, откройте инспектор: строка `WAITING FOR INPUT / OUTPUT SPACE` значит, что не хватает
входа или выход некуда выгрузить.

## Логистика

- **Разветвитель** раздаёт предметы по кругу на три стороны.
- **Сортировщик**: предметы выбранного в инспекторе фильтра идут прямо, остальные — поочерёдно вбок.
- **Переполнитель**: предметы идут прямо, пока впереди есть место; излишек — поочерёдно вбок. Удобно
  кормить главную линию в первую очередь, а остаток отправлять на склад или к турелям.
- **Мост** перебрасывает предметы до 4 тайлов над препятствиями к следующему мосту того же направления.
- **Склад** (2×2) — буфер на 300 предметов. Принимает с трёх сторон, а выдаёт только **вперёд**
  (стрелка на спрайте, поворот — R), по одному предмету за тик. Если очередной предмет не берут,
  склад пробует следующий вид — смесь не застревает перед заводом, которому нужен один из предметов.

## Энергия

| Источник | Выработка | Условие |
|---|---|---|
| Ветряк 1×1 | 2/тик | Всегда |
| Топливный генератор 2×2 | 12/тик | Пока горит уголь: 1 уголь = 4 с, т. е. 0,25 угля/с. Горит, даже если энергия никому не нужна |
| Тепловая машина 2×2 | до 4/тик | Забирает до 8 тепла/тик из тепловой сети, отдаёт 50% энергией |

**Батарея** запасает избыток и отдаёт при нехватке. При дефиците все потребители сети замедляются
одинаково: при 50% питания плавильня работает вдвое медленнее.

## Сталь и тепло

**Кузница стали**: 2 слитка + 1 уголь → 1 сталь за 2 с, 10 энергии/тик. В работе она греется на 6
тепла/тик, а сама остывает только на 1. Выше 70% заполнения тепловой ёмкости кузница замедляется
(краснеет) и при 100% останавливается. Без охлаждения это наступает через пару секунд работы.

Чем охлаждать (тепло передаётся по **тепловым трубам** и через касание сторонами):

| Охладитель | Снимает тепла/тик | Нужно |
|---|---|---|
| Радиатор 1×1 | 2 | Ничего — 3 радиатора держат одну кузницу |
| Градирня 2×2 | 8 | Вода 1/тик: **конденсатор** (2 воды/тик, 3 энергии/тик) и **трубы** |
| Тепловая машина 2×2 | до 8 | Ничего; ещё и даёт энергию |

## Оборона

### Волны

Враги появляются на краях карты по таймеру (в углу экрана: `WAVE N IN m:ss`) и идут к ближайшему ядру
по кратчайшему пути. Каждая постройка на пути «стоит» тем больше, чем она прочнее, поэтому враги
**обходят** стены, если обход не слишком длинный, и **проламывают** их, если иначе не пройти.

С каждой волной врагов больше, а с номером волны приходят новые виды. Сколько и каких врагов в
каждой волне — в разделе «Волны» [справочника контента](content-reference.md#волны); состав задаётся
данными игры и может меняться при настройке баланса.

### Шум базы

Работающие буры, производства и топливные генераторы **шумят**, и шум базы торопит врагов: таймер
волны идёт быстрее — на 2% за каждую единицу шума, но не больше чем в 2,5 раза. Простаивающие
постройки не шумят. Шум видно в углу экрана (`NOISE 12 (+24%)`; у тихой базы — `QUIET`), а шум
каждой постройки — в подсказке на панели (`NOISE 2`). Выбор за вами: быстро наращивать
производство и встречать волны раньше — или расти тише и успевать строить оборону.

### Враги

- **Ползун** (`crawler`) — быстрый и слабый, бьёт в ближнем бою.
- **Громила** (`brute`) — медленный и крепкий, сильный удар.
- **Плевун** (`spitter`) останавливается в 4 тайлах от ближайшей постройки и обстреливает её. Стены его не
  задерживают — нужна турель, достающая дальше 4 тайлов (у пушки радиус 9).
- **Панцирник** (`shellback`) — броня 8: снаряд пушки (12 урона) наносит ему только 4. Урон от брони не падает
  ниже трети исходного.

### Турели и стены

| Постройка | Сильные стороны | Требует |
|---|---|---|
| **Пушка** 2×2 | Радиус 9, 24 урона/с, бьёт с упреждением | Железные слитки лентой: 1 слиток = 2 выстрела |
| **Дуговая турель** 2×2 | Радиус 7, мгновенный разряд, **игнорирует броню**, 48 урона/с | Энергия: 8/тик во время перезарядки; при 50% питания стреляет вдвое реже. Стоит сталь |
| **Железная стена** 1×1 | Прочность 400, дешёвая | — |

Турели распределяют огонь: по врагу, которого уже добьют летящие снаряды, они не стреляют, а
берут следующую цель — несколько турелей не тратят боеприпасы на одного ползуна.

Как растёт сложность — в [отчёте о балансе](balance/2026-11-19-normal-tuned.md): сколько турелей
держат каждую волну и сколько производства нужно, чтобы их оплатить.

Совет: подводите к пушкам ленту со слитками заранее — без боеприпасов турель молчит. Против поздних
волн ставьте дуговые турели за линией пушек и не забудьте про энергию.

Если разрушено последнее ядро, партия проиграна.

## Руины

Мир Ferrustry уже был промышленным — и умер. На карте остались **руины** брошенных аванпостов:
разбитые плавильни с ветряками, буры на руде, кузницы, турели. Они не работают, но:

- **Ремонт** — клик по руине, в карточке кнопка **REPAIR**: руина превращается в рабочую постройку того же
  вида и на том же месте за **30%** её цены. Отремонтированный бур на руде сразу добывает.
- **Разбор** — снос руины (протяжка ПКМ): в ядро возвращается **50%** цены исходной постройки. Ранний
  способ добыть слитки, если аванпост стоит не там, где нужен.

Руины стоят не ближе 16 тайлов от ядра, поэтому до них надо дотянуть ленты или энергию. Враги
обходят руины или ломают их, как обычные постройки; разрушенная врагами руина ничего не даёт.
Точные цены — в разделе «Руины» [справочника](content-reference.md#руины).

## Схемы

**C** + рамка копирует постройки (с поворотами и фильтрами сортировщиков) в схему. Вставка — клик,
**R** поворачивает схему на 90°. Вставка — обычная стройка: стоимость списывается, а постройки, чьи тайлы заняты, просто не ставятся
(остальная часть схемы строится). **F6** сохраняет схему в файл, **F7** загружает. Файл схемы хранит постройки по именам,
поэтому переживает обновления игры; если постройки в игре больше нет, загрузка сообщит об этом.

## Сетевая игра

Кооператив до 8 игроков на выделенном сервере: общая база, общие ресурсы. Сервер — отдельная программа
без графики:

```bash
cargo run --release -p ferrustry-server -- --size medium --difficulty normal
```

Он слушает UDP-порт **27960** (`--port` — другой). Карту можно взять свою: `--map maps/map-001.fmap`,
или продолжить сохранение: `--load ferrustry-quicksave.fsave`. Пока в партии никого нет, она стоит.

Игроки подключаются кнопкой **JOIN** в главном меню: адрес сервера (порт можно не указывать — 27960),
**Tab** — к полю имени, **Enter** — подключиться. Игра запоминает последний сервер и имя
(`ferrustry-server.txt`). То же из командной строки:

```bash
cargo run --release -p ferrustry-client -- --connect 192.168.1.10 --name Anna
```

В углу экрана — `ONLINE PLAYER n PING x MS`. Временем управляет сервер, поэтому пауза, скорость и
загрузка сохранений в сетевой партии недоступны; **F5** сохраняет копию партии себе. Если постройка не
встала (не хватает ресурсов, клетка занята, в том числе другим игроком в тот же миг), игра скажет почему —
как в одиночной партии, только с задержкой «до сервера и обратно». Выход в главное
меню — отключение. Подключиться может только та же версия игры с теми же данными контента — иначе
сервер откажет и скажет почему.

Если на сервере не открывается порт, разрешите UDP 27960 в брандмауэре (и пробросьте его на роутере
для игры через интернет).

## Сохранения

**F5** — быстрое сохранение, **F9** — загрузка, **CONTINUE** в меню — продолжить последнее. Симуляция
детерминирована: загруженная партия продолжается бит в бит так же, как шла бы без сохранения.
Сохранения старых версий игры (до релиза) не загружаются — игра сообщит о несовпадении версии.
